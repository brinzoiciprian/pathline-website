# PATHLINE website

Site static PATHLINE (HTML, CSS și JavaScript), pregătit pentru VS Code și GitHub Pages.

## Previzualizare locală

Deschide folderul în VS Code și pornește `index.html` cu Live Preview sau Live Server.

În preview-ul încorporat din VS Code, linkurile `tel:` și `mailto:` pot fi blocate sau pot să nu aibă un program asociat. Testează-le într-un browser normal. Pe telefon, `tel:` deschide aplicația de apelare; `mailto:` deschide aplicația de e-mail configurată.

## Publicare cu GitHub Pages

1. Creează un repository GitHub pentru site.
2. Încarcă în rădăcina repository-ului conținutul acestui folder (`index.html`, `assets/` etc.).
3. În GitHub, activează Pages pentru branch-ul principal și rădăcina proiectului.
4. După publicare vei primi un URL HTTPS pe care îl poți deschide ușor și pe telefon.

## Structură

- `index.html` — homepage
- `ture.html` — ture montane
- `tururi-culturale.html` — prezentarea tururilor culturale
- `city-quests.html` — prezentarea City Quests
- `via-transilvanica.html` — Via Transilvanica
- `despre.html` — despre PATHLINE
- `contact.html` — contact
- `cultura/` — paginile orașelor
- `quests/` — paginile City Quest
- `assets/css/style.css` — stilurile comune
- `assets/js/main.js` — meniul și comportamentul paginii
- `assets/images/` — logo și imagini
